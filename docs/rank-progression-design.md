# Rank Progression Design

The rank system should create long-term mastery goals without borrowing harmful
retention pressure from competitive games.

## Product Rules

- Rank stars are awarded at batch completion, not per question.
- Big ranks have five small divisions: `青铜 5` through `王者 1`.
- Each small division needs five stars.
- Permanent rank does not drop for children.
- After `王者 1`, extra progress becomes `王者星图 N`.
- Hard or fatigue batches can still receive completion credit, but do not receive
  a bonus star.

## Current MVP Numbers

- 7 big ranks.
- 5 divisions per big rank.
- 5 stars per division.
- 175 stars from `青铜 5` to `王者 1`.
- One full batch awards 1-2 rank stars.

This changes the old 90-correct path to 王者 into a much slower, batch-quality
based path. The goal is steady long-term learning, not fast status inflation.

## Safety Position

We intentionally avoid:

- random loot-box rewards
- full-server leaderboards
- daily streak loss punishment
- rank demotion for young children
- limited-time pressure copywriting

The game layer should support competence and confidence while the adaptive
learning layer controls challenge.
